# El\_Proyecto\_Salvador

Para utilizar el Projecto y compilar desde cero necesitas las herramientas:

Code::Blocks 25.03 con MinGW
Clonar el repositorio abrir el El\_Proyecto\_Salvador.cbp, elegir el target Debug => Rebuild => Run.

EL juego se corre desde Code BLocks

se juega con WASD  y con esc se pausa.
